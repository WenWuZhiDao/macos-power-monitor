# power-monitor

轻量级 macOS 电源功率实时监控工具。周期性读取电池遥测，在浏览器里画出**三条实时功率曲线**，
并记录为 CSV，支持按时间范围（近一天 / 两天 / 三天 / 一周 / 自定义）查看。

- **零依赖**：只用 Python 3 标准库（macOS 装了命令行工具即自带 `python3`），无需 pip、无需联网。
- **轻量**：采样线程绝大多数时间在休眠，每个采样点只调用一次 `ioreg`（几十毫秒）；
  HTTP 服务空闲时几乎不占 CPU。内存中保留约一周的全精度数据用于多日曲线，
  整体内存通常约 30–60 MB，平均 CPU ≈ 0。

## 使用

```bash
cd ./macos-power-monitor

./start.sh      # 启动（后台运行）
./stop.sh       # 停止
```

启动后，在浏览器打开 **http://127.0.0.1:8765** 即可看到实时功率曲线（页面会按采样间隔自动刷新）。

> 首次使用如果提示没有执行权限：`chmod +x start.sh stop.sh`

## 三条曲线

| 曲线 | 颜色 | 含义 | 数据来源 |
| ---- | ---- | ---- | -------- |
| **总功率** | 蓝 | 适配器输入的总功率（从墙插进来的电） | `BatteryData.AdapterPower` |
| **系统实时耗电** | 黄 | 系统当前消耗的功率（CPU/屏幕/外设等） | `BatteryData.SystemPower` |
| **充电功率** | 绿 | 充入电池的功率（负值=放电） | 电池 `电压 × 电流` |

三者满足能量守恒：**总功率 ≈ 系统耗电 + 充电功率**
（小幅差异来自充电器转换损耗与三路传感器的采样时刻略有错位，属正常现象）。

典型情况：
- **插电充电**：总功率最高，其中一部分供系统、一部分进电池（绿线为正）。
- **插电但已充满**：总功率 ≈ 系统耗电，充电功率 ≈ 0。
- **未插电**：总功率 ≈ 0，系统耗电由电池供给，充电功率为负（放电）。

> 注：总功率/系统耗电字段来自 Apple Silicon 的 `BatteryData`。若在某些机型上读不到，
> 对应曲线会自动留空，充电功率曲线仍可用。

## 看什么

顶部三张卡片是三条曲线的实时数值，下面一行还有电压、电流、电量百分比、适配器额定功率。

**鼠标悬浮在曲线区**会出现竖直参考线，并在气泡里显示该时间点的精确时刻与三条曲线的数值。

## 时间范围

曲线区上方可切换查看的时间窗：

- **近一天 / 近两天 / 近三天 / 一周内**：相对当前时间的滚动窗口，会随时间自动滑动。
- **自定义**：点开后填写起止时间（精确到分钟），点「应用」即可查看任意时间段。

说明：
- 内存中保留最近约一周的全精度样本；**启动时会从 CSV 预加载历史，所以重启监控不会丢失曲线**。
- 无论选多长的范围，返回前都会自动降采样到约 2500 个点（按桶平均），保证页面流畅、传输量小。
- 自定义范围若早于内存保留窗口，会自动回退到直接读取 CSV（CSV 保存全部历史）。

## 配置（可选，环境变量）

在 `start.sh` 之前 export 即可：

| 变量            | 含义                       | 默认值   |
| --------------- | -------------------------- | -------- |
| `PM_INTERVAL`   | 采样间隔（秒）             | `5`      |
| `PM_PORT`       | 本地 HTTP 端口             | `8765`   |
| `PM_HOST`       | 绑定地址                   | `127.0.0.1` |
| `PM_RETAIN_DAYS`| 内存保留天数（覆盖最大可选范围） | `8`  |
| `PM_PLOT_POINTS`| 单次返回（绘图）的最大点数 | `2500`   |
| `PM_MAX_POINTS` | 内存样本数安全上限         | `300000` |

例如更密集地采样并换端口：

```bash
PM_INTERVAL=2 PM_PORT=9000 ./start.sh
```

## 数据文件（均在 `data/` 目录）

- `power.csv` — 全部历史采样，列：
  `iso_time,epoch,charge_w,total_w,system_w,volts,amps,soc_pct,is_charging,external,adapter_watts`
  （CSV 会持续累加，可用 Numbers/Excel/pandas 进一步分析。不需要时手动删除即可。）
- `monitor.log` — 程序运行日志。
- `monitor.pid` — 运行中的进程号（`stop.sh` 用它来停止）。

## 工作原理

`power_monitor.py` 启动一个采样线程 + 一个内置的极简 HTTP 服务：

- 采样线程每 `PM_INTERVAL` 秒执行 `ioreg -arc AppleSmartBattery`，解析出
  `Voltage`/`Amperage`（电池端，算充电功率）以及 `BatteryData` 中的
  `AdapterPower`（总功率）、`SystemPower`（系统耗电），写入 CSV 并存入内存。
- 启动时从 CSV 预加载最近约一周的数据；`/data.json?range=...` 或 `?from=&to=`
  按时间窗切片后降采样返回。
- HTTP 服务对外提供 `/`（曲线页面）与 `/data.json`（数据），
  页面用原生 Canvas 绘制曲线，无任何外部 JS 库。
